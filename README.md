# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

## 观察结论盲评与仲裁

- 切片完成「观察」步骤后自动建立盲评：两个独立鉴定槽位，提交前双方身份与票内容互不可见。
- 鉴定员各填类别与定量比例（各组分百分比、合计 100）；类别不一致或任一组分比例差超过容差时，交第三人仲裁；三人仍不一致则保持待处理。
- 鉴定员不能在同一切片重复占位；名额有时效（默认 30 分钟），超时名额可被他人抢占或通过「重派超时名额」释放。
- 鉴定标准（类别 + 容差）按版本管理，新版本只影响之后建立的盲评；进行中的盲评沿用原快照，已定稿结果不回改。
- 所有写操作串行化且原子落盘（临时文件 + 改名）：重复提交、并发抢名额只生效一次，任一写入失败不留部分票。
- 页面展示盲评状态统计、待仲裁项、冲突项和最终结论；数据存于 `data/core-slices.json`，重启仍在。
